# AIWMC Quantis — Image Master Prompts · BEFORE YOU COMMIT (Oct 19 → Nov 13)

There are 12 assets: Monday's "THE HIRE STARTS BEFORE THE REVENUE" plus #09–#19. Each matches the caption already saved in Autoposter for that date.

**Honest framing.** No prompt can guarantee a million views. Reach depends on LinkedIn distribution, timing and the first hour of comments. These prompts are built to maximise what *we* control: how fast the image stops a scroll, whether the idea is clear in one second, and the trust that makes a viewer comment and share.

---

## How to use

1. **Tool.** Use ChatGPT (GPT-image) or Ideogram. Both render exact text well. Midjourney or Flux renders text poorly; with those, use the **Textless variant** line in each prompt and add the text in Canva/Figma using the font spec below.
2. **Prompt.** Paste the **Global style block**, then the post's **Master prompt**.
3. **Size.** 4:5 portrait, 1080 × 1350.
4. **Check before posting** (60 seconds):
   - Every number on the image matches the "Exact text" list. Image models silently change digits.
   - The headline is readable at phone thumbnail size: shrink the image to 25%.
   - "Illustrative example" is visible on every image that has numbers.
   - There are no invented logos, fake UI, people, robots, brains or buildings.
   - The AIWMC Quantis wordmark is added afterwards from the **approved logo file** (`marketing/2026-10-cost-starts/logo.png`). Never use a generated logo.
5. **Attach.** Upload to the post in Autoposter (asset panel), then confirm the preview.

## Global style block (paste first, every time)

```
Brand: AIWMC Quantis — financial decision clarity for owner-operators. Editorial, precise, calm authority. Think a Financial Times infographic crossed with a premium fintech product launch — never a stock-photo ad.

Canvas: 4:5 portrait, 1080x1350. Generous safe margins (at least 72px on every side). Nothing important within 120px of the bottom edge (LinkedIn overlays).

Palette (strict):
- Background: deep navy #071526 with a barely visible fine grid (1px lines, 4% opacity) and a soft vignette.
- Primary text: warm ivory #F4F0E8.
- Accent / "good path" / emphasis: electric blue #4AA3FF.
- Risk / cost / warning: restrained amber #E79A43, used sparingly, never more than ~10% of the image.
- No other hues. No gradients except a subtle navy-to-darker-navy depth gradient.

Typography:
- Headline: heavy condensed grotesk, ALL CAPS, tight leading (0.95), left-aligned, 2–3 lines, ivory with the key phrase in electric blue.
- Numbers: bold tabular figures, very large, the visual hero.
- Labels: small monospaced uppercase with wide letter-spacing (like "MONTH 1", "ILLUSTRATIVE EXAMPLE").
- Maximum 3 type sizes. Every word perfectly spelled.

Diagram language: thin precise vector lines (2px), crisp small circular nodes, dashed lines for projections, labelled boxes with 1px ivory borders. Flat, clean, engineered. Data must look calculated, not decorative.

Header strip (top-left, small, monospaced, letter-spaced): "BEFORE YOU COMMIT · #NN". Leave the top-right 220x80px empty for the approved logo to be added afterwards.
Footer (bottom-left, small, monospaced, 60% opacity): "Illustrative example." when numbers are shown.

Composition: one idea, one focal point. Headline in the top 40%, diagram in the middle 45%, quiet footer. Strong negative space. Should read in one second at thumbnail size.
```

## The rules (16 documented principles + 6 craft rules)

Source for the 16: `docs/marketing/2026-10-15-growth-principles.md`. The repo documents **16**. A list of 22 was not found anywhere, so the 6 craft rules below are this document's addition, labelled as such. Each asset uses **one primary principle and at most one supporting principle**.

### A. Persuasion principles: what we may use now

| Principle | Use now? | How it shows up in these assets |
|---|---|---|
| Reciprocity | ✅ | Every asset *gives* a usable calculation or rule for free |
| Choice clarity | ✅ | One idea, one question, one CTA per asset |
| Halo effect | ✅ | Consistent, precise Sadewa/Quantis visual system with correct arithmetic |
| Framing | ✅ | Same number shown two ways (salary vs required revenue; break-even vs payback) |
| Loss aversion | ✅ with inputs shown | Cash *gap* shown with declared assumptions, never "money you're losing by waiting" |
| Commitment | ✅ | A small step: "change one number", "write one stop rule" |
| Mere exposure | ✅ | Numbered series, identical header strip, same palette every time |
| Anchoring | ✅ only between real figures | The peak (70h) versus the average (49h). No invented price anchors |
| Free effect | ✅ (#19) | A free walkthrough that is genuinely useful |
| Endowment | Later | Applies inside the product, not in posts |
| Scarcity | ❌ | Needs real capacity and a real end date. None exist |
| Social proof | ❌ | Needs permissioned testimonials. None exist |
| FOMO | ❌ | Needs a real event or session. None exist |
| Bandwagon | ❌ | Needs verified customer totals. None exist |
| Decoy | ❌ | Not relevant to these posts |
| Charm pricing | ❌ | No prices appear in these posts |

### B. Six craft rules (this document's addition)

17. **The 1-second test.** The idea must land at 25% scale on a phone. If it doesn't, cut words, not font size.
18. **The number is the hero.** Each image has one surprising but checkable number, larger than the headline's second line.
19. **Tension through colour.** Blue = the plan or the good path. Amber = the cost or the risk. The viewer reads the conflict before reading words.
20. **Pattern interrupt, inside the brand.** Break expectations through *the idea*, for example "$6,500 hire → $13,000", not through off-brand visuals.
21. **Verifiability = shareability.** Arithmetic a viewer can redo on a napkin makes them comment "this is exactly right" or argue the assumption. Both feed reach.
22. **Series memory.** The same header strip, grid and type every time, so the feed recognises a Quantis post before reading it.

## Variation and testing (honest A/B)
- **Variants.** For each post, generate 2 versions: **A** = the prompt as written; **B** = the same prompt, but the headline replaced by the single hero number at 2× size (for example just "$13,000" with a one-line subtitle). Post A. Keep B for a repost or a Telegram/IG version.
- **Logging.** In Autoposter weekly KPIs, log impressions and comments at 24 hours for each post. After 6 posts, compare formats by count, not percentage, because the samples are small.
- **Motion.** Only after a static asset has proven itself: animate the diagram build (lines drawing in, the number counting up) for 6–8 seconds using the isolated HyperFrames workspace.

## 1 · PROD-SAFETY OPERATING RULES (every item below obeys these)

1. **Never break prod.** Every change ships behind the existing CI gate (672 tests green) → Vercel/edge-function deploy chain. No direct prod edits except documented hotfixes.
2. **Additive-first.** New features land as new routes/components/flags; existing flows untouched until the new path is verified live.
3. **Locked invariants** (constitutional, from the master prompt): deterministic engine always returns (AI-down ⇒ `degraded:true`, never an error) · quality gates run in all modes · `cacPaybackMonths` ≠ `projectPaybackYears` · RLS on every table · no secrets behind `VITE_` · DeepSeek = own endpoint, `deepseek-v4-flash` only · benchmark count = 95,500 from one constant · free tier = 5 analyses/mo · 200-envelope for analyses · Stripe secrets never reach frontend.
4. **Measure → change → re-measure.** No improvement is "done" until its success metric is read in production.
5. **One migration at a time**, reversible, tested against a branch DB before `db push` to prod.

## 2 · THE FUNNEL MODEL (remapped from BI packages to the real product)

The prior packages' funnel science survives; the stages are renamed for Quantis reality:

```
Visitor → First analysis started → ANALYSIS COMPLETED (activation) → Signup → Return session → Paid
```

The BI insight "the product only converts after the user sees THEIR OWN data" maps directly: **Quantis only converts after a founder sees THEIR OWN idea analyzed.** The activation event is `analysis_completed` on the visitor's real idea — not a demo, not a template.

**Canonical event taxonomy (instrument exactly; some already exist in `src/lib/analytics.ts`):**
`landing_viewed` · `analysis_started {tier, anonymous}` · `analysis_completed {ok, degraded, depth}` · `free_signup_start` (exists) · `signup_completed` · `result_shared {token}` · `second_session` · `limit_reached {quota|rate}` · `upgrade_cta_clicked {surface}` · `locked_section_clicked {feature}` (= top PQL signal) · `subscription_started {tier, cycle}` · `pdf_exported`.

**Targets (from consolidated benchmarks, adjusted to current reality):**

| Stage | Current (measured/est.) | 90-day target | Source benchmark |
|---|---|---|---|
| Visitor → analysis started | ~9.5% (homepage→/app) | 20% | Single-CTA + instant-value pages convert 8–13%+ |
| Analysis started → completed | UNMEASURED | ≥85% | Abandonment <5% with honest progress UI |
| Completed → signup | ~58% (/app→auth) | 65% | Value-first signup ("save this analysis") |
| Free → paid | ~0% | 3–5% | PQL-triggered behavioral prompts convert 3.4× vs calendar |
| Trial→paid if trials added | n/a | 25%+ | 7-day trial converts 40.4% top-quartile |

# Security Policy

## Supported Versions
We actively provide security updates for the following versions:
| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |

## Reporting a Vulnerability
**Do not open a public GitHub issue for security vulnerabilities.** Please report any security concerns directly to `security@aiwmc.com`. We aim to acknowledge all reports within 24 hours and provide a resolution timeline within 72 hours.

AIWMC Quantis utilizes a multi-layer Safety Architecture; any bypass of these layers is considered a critical finding.

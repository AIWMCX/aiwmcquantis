## How to activate this master prompt

Use this prompt in a coding or browser-enabled session with access to the current Quantis repository, deployed production site, analytics, search-console evidence, and the directory-submission register where available.

Start with one activation:

```
ACTIVATE: FULL_AUDIT
MODE: READ_ONLY
ENVIRONMENT: PRODUCTION_READ_ONLY
DEPLOY: NEVER
```

Available activations:

* `ACTIVATE: DISCOVERY` — map production, repository, public routes, analytics, Search Console, and directory evidence.
* `ACTIVATE: DIRECTORY_AUDIT` — verify all 30 directory submissions, listing quality, backlink state, consistency, and referral readiness.
* `ACTIVATE: USER_TESTING` — execute role-based, task-based, moderated-simulation, accessibility, trust, and conversion testing.
* `ACTIVATE: UX_AUDIT` — inspect the complete public-to-product journey and prioritize friction.
* `ACTIVATE: TECHNICAL_SEO` — audit crawlability, rendering, canonicals, indexability, structured data, internal links, performance, and duplicate control.
* `ACTIVATE: INDEXATION` — prove discovery and index status URL by URL using authoritative evidence.
* `ACTIVATE: ON_PAGE_SEO` — align pages with buyer intent without keyword stuffing or unsupported claims.
* `ACTIVATE: ANALYTICS` — establish privacy-safe attribution, funnel measurement, directory cohorts, and activation events.
* `ACTIVATE: P0_FIXES` — implement only safe, local, test-backed critical corrections; never deploy.
* `ACTIVATE: FULL_AUDIT` — run all phases in dependency order and maintain a resumable evidence ledger.

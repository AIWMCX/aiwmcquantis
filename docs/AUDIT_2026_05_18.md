# AIWMC Quantis — Technical Condition Audit

_Date: 18 May 2026 · Scope: post-Benchmark-First hardening + CI/CD overhaul_

## CI / CD
- **CI workflow (`.github/workflows/ci.yml`)**: 6 named steps — Lint, Prettier (scoped), Typecheck (financial), Spec-hash verify, Tests (incl. new contract suite), Dependency audit. Each step has a failure-hint annotation. Artifacts uploaded for 14 days: `lint-output.txt`, `lint-report.json`, `test-output.txt`, `audit-report.txt`, `coverage/**`. Bun cache + 20-min timeout + concurrency cancellation.
- **Staging (`staging-deploy.yml`)**: Per-PR build via the `staging` GitHub Environment. Auto-detects Vercel or Netlify secrets; if neither is present it logs the exact env-var names to set, so the workflow is never red — just informational.
- **Production (`production-deploy.yml`)**: Triggers on `workflow_run` success of CI on `main`. Uses `production` environment (configure required reviewers there for a manual gate). Same auto-detect pattern.
- **Local CI parity**: `bun run pre-commit` runs the full chain in <30 s on a warm cache.

## Analysis Pipeline (Benchmark-First)
- Zod boundary schemas reject malformed engine output before it reaches the UI/PDF.
- `metadata.benchmarks[]` is the single source of truth — surfaced via `BenchmarkRecordsBlock` (dashboard) and `ReportBenchmarks` (PDF), now with **one-click CSV export** (P25/Median/P75/match_type + source/date/unit).
- `AnalysisErrorPanel` now tracks **attempt count**, applies **exponential backoff** (2^(n-1) s, capped at 30 s), reassures users that **inputs are preserved**, and gives up cleanly at 5 attempts.
- QuantisHealth shows a **top alert banner** when: Benchmark Coverage <80% (warn) or <50% (critical), Direct-Match Share <30%, Invariants Passing <95%, or invariant telemetry is dead.
